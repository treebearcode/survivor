# Credits

## V1 art — procedural / original

All characters, enemies, the boss, gems, bullets, blades, pickups,
stars and nebulae in V1 are drawn in code with Phaser Graphics
(`src/game.js`, `make*Texture`). No external images, no copied
names. "Starfall Survivor", "Nova", and the enemy designs are original.

## Phaser

Phaser 3.60.0, bundled locally in `src/assets/phaser.min.js` and inlined
into `dist/index.html`. Phaser is released under the MIT licence.
https://phaser.io/ — https://github.com/photonstorm/phaser

## Sounds

All sounds in V1 are synthesized with the Web Audio API in `src/game.js`
(`beep()`). No external audio files.
